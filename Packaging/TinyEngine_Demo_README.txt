TinyEngine Lighting Demo

실행 방법
- Windows 10/11 x64에서 TinyEngine.exe를 실행합니다.

조작
- WASD: 캐릭터 이동
- ESC: 종료
- Radiance Cascades 체크박스: RC Lighting 켜기/끄기

포함 기능
- DirectX 11 Sprite Renderer
- Tiled JSON 맵 로딩과 충돌
- Radiance Cascades 기반 2D Lighting
- RenderDoc GPU Event Marker
- D3D11 Timestamp Query 기반 GPU Pass Timing
